# 操作文档

以下命令均在项目根目录执行。

## Windows

### 首次安装工具链
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_tools.ps1
```

### 编译
```powershell
# 完整构建（重新提取素材，需要 ffmpeg 和 Python）
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

# 仅编译（使用已有素材）
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipAssets
```

### 运行
```powershell
.\dist\QtCatPet.exe
```
发布时直接拷贝整个 `dist\` 目录即可。

## Linux

### 编译
```bash
./scripts/build.sh
# 仅编译（使用已有素材）
SKIP_ASSETS=1 ./scripts/build.sh
```

### 运行
```bash
./dist/QtCatPet
```
