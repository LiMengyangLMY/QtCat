# QtCat 架构与功能说明

本文档记录 QtCat 桌面宠物的当前真实代码架构、三种运行形态、多格式电子书解析、内置书库持久化及“小猫跑酷”小游戏的实现机制。

---

## 一、 核心模块划分

| 模块文件 | 职责说明 |
| :--- | :--- |
| `src/main.cpp` | 程序入口，初始化 `QApplication`、全局猫咪图标与主窗口 |
| `src/desktoppet.h/.cpp` | 主窗口容器：管理无边框全透明置顶窗口、三种形态尺寸切换、悬停旋转动画、阅读控件与前进/后退按钮、全局右键菜单及老板键调度 |
| `src/ebookparser.h/.cpp` | 多格式电子书解析器：支持 `.txt`、`.epub`、`.mobi`、`.azw`、`.azw3` 正文提取与 HTML 清洗 |
| `src/novelmanager.h/.cpp` | 书库与设置管理：内置书库 `dist/books/` 导入去重、`dist/bookshelf.csv` 原子读写、阅读进度与外观偏好（颜色/字号/显隐）管理 |
| `src/bookdialog.h/.cpp` | 摸鱼书架弹窗：无边框深色卡片，支持点击/拖拽选书、内置书库双击续读、删除选中书籍、编码切换与首段防乱码预览 |
| `src/catrunnerwidget.h/.cpp` | 小猫跑酷小游戏：60FPS 物理循环、一段跳/旋转二段跳、像素风障碍与半空飞来黄瓜、5 鱼干无敌冲刺、冻结存档与最高分记录 |

## 二、 三种窗口形态与布局切换

主窗口固定开启 `Qt::FramelessWindowHint | Qt::Tool | Qt::WindowStaysOnTopHint` 与 `Qt::WA_TranslucentBackground`，根据当前状态在三种无边框全透明形态间切换：

```
[1. 纯桌宠形态]           [2. 摸鱼看小说形态]              [3. 小猫跑酷形态]
  256 × 256                 256 × 384                      460 × 180
+-------------+         +-----------------+      +-------------------------------+
|             |         |   猫咪本体       |      | [鱼干槽]            HI / 得分 |
|  猫咪本体    |         |   256 × 256     |      |    猫咪   像素仙人掌 / 飞黄瓜  |
|  256 × 256  |         +-------------+---+      | ═══════════ 像素跑道 ═════════ |
|             |         | 透明阅读框   | ▲ |      +-------------------------------+
+-------------+         | 232 × 128   | ▼ |
                        +-------------+---+
```

- **悬停分区**：阅读形态下，仅当鼠标位于上方 `256 × 256` 猫本体区域时触发 15fps 旋转动画；鼠标移至下方阅读区操作按钮或滚轮时猫咪保持静止，不干扰视线。
- **边界自适应**：展开为 `460 × 180` 跑酷跑道时，若窗口靠近屏幕右边缘会自动向内平移防越界；退回桌宠/阅读形态时自动恢复原桌面坐标。

## 三、 摸鱼看小说与多格式解析引擎

### 1. 透明阅读区与排版
- 阅读框采用只读 `QPlainTextEdit`（关闭滚动条与光标焦点，开启 `Qt::WA_TransparentForMouseEvents` 将拖拽/滚轮/右键透传给主窗口），右侧搭配 `24px` 宽的半透明 `▲`（上划一行）/ `▼`（下划一行）按钮。
- 默认字号 `8pt`（紧凑比例行高 `102%`），支持 `4 ~ 20pt` 菜单档位、自定义输入及 `Ctrl + 滚轮` 实时缩放；缩放字号时自动按当前百分比换算行号，保持阅读位置不漂移。
- 文字颜色支持纯白 (`#FFFFFF`)、浅灰 (`#D0D0D0`)、中灰 (`#888888`)、深灰 (`#444444`)、纯黑 (`#000000`) 及调色板自定义色。
- **自动播放**：开启后以 **1.5 秒/行** 匀速下划；手动点 `▲/▼` 或滚轮后自动重置 1.5 秒计时；双击猫咪或按 `Esc` 隐蔽文字时**立即停止自动播放**并保存进度。

### 2. 多格式解析原理（`EbookParser`）
- **`.txt`**：先以 `UTF-8` 校验解码，若存在非法字节序列则自动回退 `GB18030`（兼容 GBK/GB2312），也可在书架面板手动指定编码。
- **`.epub`**：使用 Qt `QZipReader` 直接内存解包，解析 `META-INF/container.xml` 定位 `.opf`，按 `<spine>` 章节阅读顺序提取 XHTML 并通过 `QTextDocument` 转为干净流式纯文本。
- **`.mobi` / `.azw` / `.azw3`**：解析 PalmDB 记录表与 Record 0 中的 PalmDOC / MOBI 头，先按偏移 `242` 处的 `extra_flags` 剥离每个文本块末尾的多字节重叠与变长附加数据（防止产生 `\0` 截断正文），再执行 PalmDOC LZ77 解压与 HTML 标签清洗。

## 四、 内置书库与 CSV 进度持久化（`NovelManager`）

为彻底解决“原电子书在磁盘上被移动/改名导致失效”及“高频写注册表”问题，采用 **内置书库 + CSV 定时/退出落盘** 方案：

1. **内置书库 `dist/books/`**：
   - 导入书籍（拖拽或书架选择）时自动将其拷贝至 `dist/books/`，并通过 SHA-256 内容哈希自动去重（同一本书从不同路径再次拖入会自动复用副本并继承旧进度；同名不同内容文件自动追加 8 位短哈希后缀）。
   - 在书架面板点击 **🗑️ 删除选中** 仅移除记录与 `dist/books/` 内的副本，绝不触碰用户原磁盘文件。
2. **便携进度表 `dist/bookshelf.csv`**：
   - 字段：`file_path,file_name,progress_pct,scroll_pos,total_scroll,last_read_time`（其中 `file_path` 存 `books/xxx` 相对路径，整个 `dist/` 拷走换电脑依然有效）。
   - 采用 **UTF-8 带 BOM** 编码与标准双引号转义（Excel 双击直接打开不乱码），并通过 `bookshelf.csv.tmp` 临时文件原子覆盖写入防止异常断电损坏。
3. **落盘时机与恢复策略**：
   - 日常翻行仅更新内存并标记脏位（零磁盘 I/O）；
   - **每 5 分钟**定时检查脏位自动落盘（异常退出兜底）；
   - **主动退出**（`aboutToQuit`）、**切书**、**收起小说框**、**手动输入 `x%` 绝对进度跳转**时立即落盘；
   - 下次启动自动打开最近一本书：总行数未变时按 `scroll_pos` 精确到原行，字号改变导致总行数变化时按 `progress_pct` 比例还原。

## 五、 小猫跑酷小游戏（`CatRunnerWidget`）

- **画面与防穿透细节**：在 `460 × 180` 画布底层绘制 `QColor(0, 0, 0, 1)`（肉眼完全透明，但 Alpha > 0），防止在 Windows 分层透明窗口空白处点击跳跃时穿透到底层桌面软件。
- **跳跃与动作**：主角使用原高清猫咪平滑缩放到 `56 × 56`；支持 **空格 / `W` / `↑` / 鼠标左键** 一段跳与空中二段跳（左键快速连点已将 `mouseDoubleClickEvent` 转发给跳跃逻辑，不与老板键冲突），二段跳自动播放 14 帧高速旋转动画。
- **障碍与道具**（我的世界像素风，`Qt::FastTransformation` 保留锐利像素边缘）：
  - **地面障碍**：单株像素仙人掌、双株仙人掌簇、地面像素黄瓜；
  - **空中障碍**：得分达标后按概率生成高低两档**半空飞来黄瓜**（高空可不跳直接钻过，中低空需跳过或二段跳越过）；
  - **蓝色小鱼干**：吃一条 `+15` 分并积累 1 格充能，集满 **5 条**触发 **3 秒高速旋转无敌冲刺**（速度提升 `1.55x`，直接将沿途障碍物旋转撞飞并额外 `+20` 分）。
- **老板键冻结存档**：游戏中按 **`Esc`** 或点击**鼠标中键**，立即将当前局所有实体坐标、速度、得分与充能状态冻结在内存，窗口瞬时切回 `256 × 256` 静止大猫；右键点击 **【🎮 继续小猫跑酷 (已冻结存档)】** 即可原位恢复。
