# “摸鱼看小说”功能设计方案

本文档整理了 QtCat 桌面宠物新增“摸鱼看小说”功能的完整需求、界面设计与技术实现方案，作为后续开发的基准设计文档。

---

## 一、 核心需求

1. **导入小说**：支持导入本地 `.txt` 小说文件，兼容中文常见编码（UTF-8 / GBK / GB18030）。
2. **显示区域**：位于“猫”本体正下方，宽度与猫等宽（`256px`），高度为猫的 50%（`128px`）。
3. **文字颜色**：支持从白到黑（灰阶及自定义色）调节，适配不同深浅桌面壁纸。
4. **全透明背景**：文本框背景 100% 完全透明，无边框、无滚动条，仅显示纯文字。

---

## 二、 视觉与几何布局

```
+-----------------------------+
|                             |
|          猫咪本体           |  尺寸：256 × 256
|       (静止 / 旋转动画)      |
|                             |
+-----------------------------+
|                             |  尺寸：256 × 128 (高度为猫的 50%)
|         全透明文本框        |  背景：100% 透明，无边框，无滚动条
|      (文字显示 / 滚轮翻页)   |  颜色：白 ~ 黑可调，字号可调
+-----------------------------+
```

- **窗口动态尺寸**：
  - 阅读模式：`256 × 384`（上部 `256 × 256` 猫本体 + 下部 `256 × 128` 文本框）。
  - 隐蔽模式（老板键关闭文本框）：窗口收缩回 `256 × 256` 纯桌宠形态。
- **全透明渲染**：
  - 依托窗口已开启的 `Qt::WA_TranslucentBackground` 属性。
  - 下方文本控件采用只读 `QPlainTextEdit`（禁用文本选中光标与焦点框、关闭横纵滚动条），样式表配置为：
    ```css
    background: transparent;
    border: none;
    padding: 4px;
    ```
- **初始未导入状态**：
  - 文本框内以低对比度浅灰小字提示：*“右键导入小说 或 拖拽 .txt 文件到小猫身上～”*。

## 三、 导入界面设计

为兼顾“零干扰摸鱼”和“多本管理”需求，提供 **两种导入通道** + **轻量级专属导入面板**：

### 1. 两种导入通道
- **拖拽直入（零弹窗，推荐）**：直接将本地 `.txt` 文件拖至猫咪窗口松开，立即识别编码并开始阅读，无任何系统弹窗。
- **右键菜单呼出**：右键点击猫咪 → 选择 **“导入小说 / 摸鱼书架...”**，打开专属轻量管理面板。

### 2. 专属“摸鱼书架与导入面板”
采用无边框深色磨砂小卡片风格（约 `420 × 340px`），避免大面积白色系统弹窗在桌面过于显眼：

```
+-------------------------------------------------------+
|  📖 摸鱼书架与小说导入                          [—] [✕] |
+-------------------------------------------------------+
|                                                       |
|   + - - - - - - - - - - - - - - - - - - - - - - - +   |
|   |   📂 点击浏览本地 TXT 文件                     |   |
|   |      或 将 .txt 文件拖拽到此处导入              |   |
|   + - - - - - - - - - - - - - - - - - - - - - - - +   |
|                                                       |
|  📚 最近阅读书架（自动记忆进度）                       |
|  +-------------------------------------------------+  |
|  | 1. 《凡人修仙传》.txt     [已读 42%]   [继续阅读]  |  |
|  | 2. 《诡秘之主》.txt       [已读 15%]   [继续阅读]  |  |
|  | 3. 《三体全集》.txt       [已读  8%]   [继续阅读]  |  |
|  +-------------------------------------------------+  |
|                                                       |
|  ⚙️ 编码校验与预览                                     |
|  编码识别: [ 自动识别 (UTF-8)  ▼ ]  (可切换 GBK/GB2312) |
|  首段预览: "山脚下的青牛村，天色刚蒙蒙亮，炊烟已起..."   |
|                                                       |
|                    [ 确认导入并开读 ]                  |
+-------------------------------------------------------+
```

- **拖拽/浏览区**：支持点击调起文件选择器或直接拖入 `.txt`。
- **编码自动嗅探与防乱码预览**：优先尝试 `UTF-8`，检测到非法字节自动回退 `GB18030`（覆盖 GBK/GB2312），并实时展示前 3 行正文供确认。
- **最近书架**：通过 `QSettings` 记忆最近 5 本书的路径、进度百分比与滚动偏移，支持一键续读与进度条快速跳转。

## 四、 颜色与样式调节

通过右键菜单“文字样式”子菜单即时调整，并自动持久化保存：

1. **快捷灰阶预设（白 → 黑）**：
   - 纯白 (`#FFFFFF`) — 深色壁纸
   - 浅灰 (`#D0D0D0`) — 柔和低刺眼
   - 中灰 (`#888888`) — 推荐摸鱼档，隐蔽度最高
   - 深灰 (`#444444`) — 浅灰背景
   - 纯黑 (`#000000`) — 亮色/纯白背景
2. **自定义颜色**：提供 `QColorDialog` 拾色器自由微调明暗与颜色。
3. **字号调节**：支持 `8pt ~ 14pt` 放大/缩小。

## 五、 阅读与“摸鱼”交互设计

| 场景 | 操作方式 | 行为表现 |
| :--- | :--- | :--- |
| **一键隐蔽（老板键）** | **双击猫咪** 或 按 **`Esc`** | 瞬间隐藏下方文本框，窗口缩回 `256 × 256` 纯桌宠；再次双击恢复阅读 |
| **平滑翻行/翻页** | 鼠标滚轮 / 方向键 ($\uparrow\downarrow$) / PageUp・PageDown | 驱动隐藏滚动条平滑滚动，并实时保存阅读位置 |
| **悬停动画分区** | 鼠标进入上方 `256 × 256` 区域 | 仅悬停在猫本体时触发旋转动画；在下方文本框阅读滚轮时猫咪保持静止不打扰 |
| **窗口移动** | 左键按住拖拽 | 整体移动桌宠与阅读框 |
| **功能菜单** | 鼠标右键单击 | 导入小说/书架、显示/隐藏文本框、文字颜色、字号、退出 |

## 六、 代码模块规划

```
src/
├─ main.cpp
├─ desktoppet.h/.cpp        # 主窗口：垂直布局（猫本体 + 阅读框）、拖拽、老板键、右键菜单
├─ novelreader.h/.cpp       # 透明阅读控件：全透明样式、滚轮/键盘翻页、颜色与字号控制
├─ novelmanager.h/.cpp      # 数据与持久层：TXT 多编码解析、历史书架与进度存储 (QSettings)
└─ bookdialog.h/.cpp        # 轻量导入与书架弹窗：拖拽区、最近书架、编码预览
```

### 实施阶段
1. **阶段 1（核心阅读）**：主窗口改为垂直布局，加入 `256 × 128` 全透明文本框、滚轮翻页、双击/Esc 老板键及白到黑颜色切换。
2. **阶段 2（导入与编码）**：支持直接拖入 `.txt` 与 UTF-8/GB18030 自动识别，接入 `QSettings` 断点续读。
3. **阶段 3（书架面板）**：实现无边框磨砂风格“摸鱼书架与导入面板”，提供历史记录管理与首段防乱码预览。
4. **阶段 4（编译验证）**：更新 `DesktopPet.pro` 并通过 `scripts/build.ps1 -SkipAssets` 编译打包验证。
