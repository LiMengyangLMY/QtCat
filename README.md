# QtCat

一个基于 C++17 / Qt 5 Widgets 的全透明桌面宠物办公摸鱼工具，集成了**互动旋转桌宠**、**多格式全透明小说阅读器（内置独立书库）**与**小猫跑酷桌面小游戏**。

> - **普通用户（免安装下载即用）**：请直接切换到本仓库的 **`release`** 分支 → 点击右上角 **Code → Download ZIP** 解压 → 双击 `启动桌宠.bat` 或 `创建桌面快捷方式.bat` 即可使用，无需安装任何开发环境。  
> - **开发者 / 维护者**：当前 **`main`** 分支存放完整源码、素材与自动化构建/发布脚本。

## 一、 核心功能

### 1. 桌面宠物主体
- 默认在桌面右下角展示 `256×256` 高清抠图静止小猫，鼠标悬停在猫身上时循环播放 `15fps` 魔性旋转动画；
- 无边框、100% 透明背景、窗口置顶，按住鼠标左键可随意拖拽位置。

### 2. 摸鱼看小说（多格式 + 内置书库）
- **多格式原生解析**：支持 **`.txt`、`.epub`、`.mobi`、`.azw`、`.azw3`**（自动嗅探 UTF-8 / GB18030 编码，内置 EPUB 解包与 PalmDOC LZ77 解码）。
- **双通道导入与防丢书库**：支持将电子书直接拖到小猫身上零弹窗开读，或通过暗色“摸鱼书架”面板管理；导入后自动拷贝去重至 `dist/books/`，原磁盘文件移动或删除也不受影响。
- **全透明隐蔽排版**：猫咪正下方 `256×128` 全透明无边框文本区，支持纯白到纯黑多档灰阶及自定义文字色、`4~20pt` 字号微调（默认 `8pt`，支持 `Ctrl + 滚轮` 实时缩放）。
- **手动 / 自动阅读与进度持久化**：右侧配半透明 `▲/▼` 单行翻动按钮，支持 **`1.5s/行` 自动播放** 与 **`x%` 绝对进度跳转**；阅读进度保存在 `dist/bookshelf.csv`（主动退出立即落盘 + 每 5 分钟自动兜底）。

### 3. 小猫跑酷小游戏（Chrome 小恐龙全透明版）
- 右键选择 **【🎮 小猫跑酷小游戏】** 即可展开 `460×180` 全透明横版跑道；
- 支持一段跳与**高速旋转二段跳**，躲避我的世界像素风仙人掌与地面/半空飞来的黄瓜；
- 吃**蓝色小鱼干**加分并充能，集满 **5 条**触发 **3 秒高速旋转无敌冲刺**，直接撞飞沿途障碍物得分；自动记录历史最高分 `HI`。

## 二、 快捷交互一览

| 模式 | 操作方式 | 效果 |
| :--- | :--- | :--- |
| **通用** | 左键按住拖拽 / 右键单击 | 移动窗口位置 / 打开功能菜单 |
| **看小说模式** | **左键双击猫咪** 或 **`Esc`** | **老板键**：立即隐藏小说框并停止自动播放，缩回 `256×256` 静止猫 |
| **看小说模式** | 点击右侧 `▲` / `▼`、滚轮、`↑/↓`、`J/K` | 手动逐行上划 / 下划（`Shift + 滚轮` 整屏翻 4 行） |
| **看小说模式** | **`Space`（空格）** 或 **鼠标中键** | 开启 / 暂停 `1.5s/行` 自动播放 |
| **看小说模式** | **`Ctrl + 鼠标滚轮`** | 实时放大 / 缩小字号（自动保持当前阅读百分比位置） |
| **小猫跑酷模式** | **`Space` / `W` / `↑`** 或 **鼠标左键单击/连点** | 一段跳 / 空中二段跳（二段跳触发高速旋转动画） |
| **小猫跑酷模式** | **`Esc`** 或 **鼠标中键（滚轮按下）** | **老板键**：冻结当前局存档并立即退回 `256×256` 静止大猫 |

## 四、 快速构建与运行（Windows）

```powershell
# 1. 首次准备：自动安装 Qt 5.15.2 与 MinGW 到 third_party/qt（约 1GB）
powershell -ExecutionPolicy Bypass -File .\scripts\install_tools.ps1

# 2. 编译并部署运行库到 dist\（使用已有 PNG 素材，无需安装 ffmpeg）
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipAssets

# 3. 启动桌宠
.\dist\QtCatPet.exe
```

*(Linux 构建、素材重提与常见问题排查详见 [`docs/开发与分支维护指南.md`](docs/开发与分支维护指南.md)。)*

## 五、 仓库分支结构与版本发布

本仓库维护两条职责隔离的独立分支（本地只需保留一个目录并始终停留在 `main` 分支工作，**无需手动切换分支**）：

- **`main` 分支（开发测试）**：仅保存源码、素材、脚本与文档，常规增量提交。
- **`release` 分支（下载即用）**：由 [`scripts/publish_release_branch.ps1`](scripts/publish_release_branch.ps1) 在临时净室自动组装生成的**单提交孤儿分支**，包含可独立运行的 `dist/`（自动剔除个人 `books/` 与 `bookshelf.csv`）及相对路径启动/创建桌面快捷方式脚本，每次覆盖更新以保持仓库体积恒定。

日常改完代码并编译验证后，依次执行以下命令即可同步推送双分支：

```powershell
git add .
git commit -m "feat: 本次更新说明"
git push origin main

powershell -ExecutionPolicy Bypass -File .\scripts\publish_release_branch.ps1 -Push
```
