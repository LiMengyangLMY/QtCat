# QtCat 桌面宠物（下载即用版）

本分支为**打包即用发行分支**，无需安装 Qt 或任何开发环境，下载解压即可直接运行。  
*(如需查看源码或参与开发，请切换至 `main` 分支。)*

## 快速开始

1. 点击 GitHub 页面右上角 **Code → Download ZIP** 下载并解压到任意目录；
2. 双击 **启动桌宠.bat** 即可直接启动小猫；
3. 如需在桌面创建图标，双击 **创建桌面快捷方式.bat** 即可自动按当前路径生成带猫咪图标的桌面快捷方式。

## 使用说明

- **移动位置**：鼠标左键按住拖拽
- **旋转动画**：鼠标悬停在猫咪本体上
- **导入电子书**：支持 `.txt` / `.epub` / `.mobi` / `.azw` / `.azw3`，直接将电子书拖到小猫身上即可导入（或右键打开“摸鱼书架”管理与删除）
- **手动翻行**：点击文本框右侧 `▲` / `▼` 按钮，或使用鼠标滚轮 / 键盘 `J`・`K`・方向键
- **自动播放与跳转**：右键菜单 / 空格键 / 鼠标中键启停自动播放（每行 1.5 秒）；右键支持输入 `0.0 ~ 100.0%` 绝对进度跳转
- **一键隐蔽（老板键）**：看小说时双击猫咪主体或按 `Esc` 键瞬间隐藏文字并停止自动播放
- **字号与颜色**：右键菜单可调白到黑颜色、多档字号与自定义字号，也支持 `Ctrl + 滚轮` 实时缩放
- **便携书库保存**：导入的电子书自动存入 `dist/books/`，阅读进度保存在 `dist/bookshelf.csv`（主动退出立即保存 + 每 5 分钟自动兜底；将整个文件夹拷走换电脑可保留全部书籍与进度）
- **小猫跑酷小游戏**：右键选择【🎮 小猫跑酷小游戏】展开 460×180 全透明跑道，空格/左键起跳与连点二段跳，躲避像素仙人掌与飞空黄瓜，攒满 5 条蓝色鱼干触发 3 秒高速旋转无敌冲刺；按 `Esc` 或鼠标中键立即冻结存档并退回静止大猫
